# Монитор ВЧ2 (RfnMonViewer)

Программа читает атрибуты Tango 8 резонаторов (по 5 девайсов: mod, ctrl, cav, tuner, sspa),
рисует их на 4 графиках и пишет по файлу `.dat` на каждый резонатор.
Программа только **читает** атрибуты, в оборудование ничего не пишет.

## Файлы

| Файл | Что это |
|---|---|
| `rfn_mon/rfn_mon_viewer.py` | главное окно `RfnMonWindow` |
| `rfn_mon/rfn_mon_data.py` | `RfnMonData`: данные одного резонатора |
| `rfn_mon/rfn_mon_plot_dialog.py` | окно выбора линий одного графика |
| `RfnMonViewer-config.json` | боевой конфиг |
| `fake_server.py` | фейковый Tango-сервер для стенда (без базы) |
| `make_test_config.py` | делает `test-config.json` для стенда из боевого конфига |
| `check_lab.py` | проверка девайсов и атрибутов по конфигу (только чтение) |

Порядок групп в `tango_attr` должен совпадать с порядком девайсов в `devices`:
группа j читается с девайса j (по позиции, не по имени). Проверяется `check_lab.py`.

## Установка (Windows, cmd)

Нужен Python 3.8 (под pytango 9.3.4 на Windows нет сборок под новее).

```bat
py -3.8 -m venv venv
venv\Scripts\activate
pip install pytango==9.3.4 PyQt5 pyqtgraph "numpy<1.24"
```

## Стенд

Каждую команду запускать в своём окне cmd из папки проекта, с `venv\Scripts\activate`.

Обычный запуск (все 8 резонаторов на порту 10000):

```bat
python fake_server.py
python make_test_config.py
python run_test.py
```

Параметры `fake_server.py`:

- `--port 10001` порт (по умолчанию 10000);
- `--res 1-4` какие резонаторы поднимать: диапазон `1-4`, список `2,5,7` или имена `1e1,3e2`.
  Номера с 1, в порядке `devices` в конфиге. По умолчанию все.

Параметры `make_test_config.py`:

- `--port 10001` порт для всех резонаторов;
- `--split 10001` резонаторы 1-4 на `--port` (10000), 5-8 на 10001;
- `--out имя.json` куда записать (по умолчанию `test-config.json`).

### Сценарии отказов

1. **Сервер без части резонаторов.**
   `python fake_server.py --res 1-6`, `python make_test_config.py`, `python run_test.py`, Mon: Start.
   Ожидается: «Резонаторы: 6 из 8», одно окно со списком 3e2, 4e2, графики идут, 6 новых файлов.
2. **Остановка сервера посреди работы.**
   `python fake_server.py`, `python make_test_config.py`, `python run_test.py`, Mon: Start,
   через несколько секунд Ctrl+C в окне сервера.
   Ожидается: окно «Потеряна связь со всеми резонаторами, мониторинг остановлен»,
   «Резонаторы: ---», программа не падает, графики остаются.
3. **Два сервера, остановка одного.**
   `python fake_server.py --res 1-4` и `python fake_server.py --res 5-8 --port 10001`
   (два окна), `python make_test_config.py --split 10001`, `python run_test.py`, Mon: Start,
   затем Ctrl+C во втором сервере.
   Ожидается: одно окно-предупреждение со списком 1e2, 2e2, 3e2, 4e2, «Резонаторы: 4 из 8»,
   резонаторы 1-4 продолжают рисоваться и писаться в файлы.

### Проверка девайсов

```bat
python check_lab.py test-config.json
python check_lab.py
python check_lab.py --host 10.18.113.66:10000 --timeout 3000
```

Без аргумента берётся `RfnMonViewer-config.json`. `TANGO_HOST` берётся из окружения,
если не задан, то `10.18.113.66:10000`. Код выхода 0, если замечаний нет, иначе 1.

## Поведение при отказах

- **Mon: Start.** Подключается к каждому резонатору отдельно. Резонатор недоступен, если не
  отвечает любой из его 5 девайсов. Недоступны все: окно ошибки, мониторинг не стартует.
  Недоступна часть: мониторинг идёт с остальными, одно окно со списком. Для недоступных
  файл не создаётся. Пинг ждёт ответа не дольше 1 с (`PING_TIMEOUT_MS` в `rfn_mon_data.py`).
- **Во время работы.** Если резонатор перестал отвечать, его недописанный отсчёт убирается,
  он больше не опрашивается и не пишется в файл, предупреждение показывается один раз.
  Снова его опросят после Mon: Stop / Mon: Start. Если потеряны все, мониторинг останавливается.
- **Read from file.** Можно выбрать несколько файлов; резонатор определяется по началу
  имени файла (`rf2-1e1_...dat`).

Не коммитить: `venv/`, `data/`, `test-config.json`, `*-lines.json`.
